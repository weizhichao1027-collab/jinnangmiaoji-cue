隐私政策

最后更新：2026-09-18

听写笔记（Dictation Notes）是一款用户自带 API Key 的对话转录与 AI 辅助应用，适用于 iPhone 与 Mac。我们不为这个应用运营后端，也不会从应用里收集、出售或追踪个人数据。

发布方

本应用由 Shanghai Qishan Cultural Communication Co., Ltd. 在 App Store 发布。版权标注为 © 2026 Zhichao Wei。隐私问题请写到 281916057@qq.com。

我们不收集的数据

我们没有开发者服务器来接收账号、分析事件、广告标识符或崩溃档案。应用本身不内置追踪 SDK，也不做跨应用追踪。

保存在你设备上的内容

API Key、转录、录音、设置和历史会话默认只保存在本机。iOS 上密钥写在系统钥匙串；你可以随时清除。除非你主动导出或分享，这些内容不会传到我们这里。我们也没有地方接收它们。

你配置的服务商

当你开始云端转录或向 AI 提问时，音频、文字和提示词会由应用直接发送给你选择的服务商，例如语音识别服务、兼容的对话补全接口，或你自己的网关。这些服务商按他们自己的条款处理数据，也可能在其他国家处理。请只配置你信任的服务商。

录音与同意

录音和转录可能包含敏感对话。你需要在合法、并获得必要同意的情况下使用录音、转录或总结。首次听写前，应用会再次提示这一点。

购买

一次性买断由 Apple 通过 App Store 处理。我们不会接收或保存支付卡信息。Apple 可能按自己的隐私政策处理购买收据。这是非消耗型一次性买断，不是自动续期订阅。

App Store 隐私标签

本应用在 App Store 的隐私标签为开发者「不收集数据」。用户自选服务商收到的音频或文字，不属于开发者收集的数据。

本网站

这些页面是放在 GitHub Pages 上的静态文件。我们不在本站运行分析、广告或追踪 SDK。浏览器可能把语言偏好存在 localStorage。GitHub 可能按自己的政策处理访问日志（例如 IP 地址）。

你能自己做的控制

你可以在应用里删除会话、录音和密钥。卸载应用会去掉这台设备上的本地历史。若不想再向某家服务商发送新的音频或文字，删掉对应 Key，或改回本机听写。

儿童

本应用不面向 13 岁以下儿童，也不会故意收集儿童的个人数据。

变更

若本政策有实质变更，我们会更新日期并在此页公布。继续使用即表示你了解更新后的说明。

联系

隐私问题请写信给 281916057@qq.com，并说明设备、系统版本和应用版本。请不要在邮件里粘贴 API Key 或未脱敏的录音。
