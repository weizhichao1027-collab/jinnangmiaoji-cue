- Support: `support.html`
- Terms: `terms.html`

Public URLs (GitHub Pages):

- https://weizhichao1027-collab.github.io/jinnangmiaoji-cue/privacy.html
- https://weizhichao1027-collab.github.io/jinnangmiaoji-cue/support.html
- https://weizhichao1027-collab.github.io/jinnangmiaoji-cue/terms.html

Publish by copying this folder to the `jinnangmiaoji-cue` GitHub Pages repository (or set Pages to serve `store-site/` from this repo). After changing copy, run `python3 build-i18n.py` to regenerate `site.js`.
