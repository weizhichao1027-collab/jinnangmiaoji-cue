技术支持

写信前请带上这些信息，处理会快很多。

  • 设备型号和系统版本
  • 应用版本
  • 问题出在 iPhone、Mac，还是两端都有
  • 设置里选的转录和 AI 服务商
  • 现象和屏幕上的错误原文

请不要发送 API Key、私人录音或未脱敏的转录，除非你明确决定分享。

写信给 281916057@qq.com

本机听写没有出字

先允许麦克风。本机听写还需要语音识别权限。到系统设置打开这两项后，回到应用再点开始。部分语言若没有离线模型，会走 Apple 的语音识别。

怎么接自己的 API

打开设置，选一家 AI 或转录服务商，粘贴 Key，点保存并测试。常见服务商不用改地址和模型。本机听写可以先用，不必填转录 Key。

试用和买断怎么算

本机听写不计数。云端转录和 AI 接话一共可以试用 20 次，之后一次性买断。这不是自动续期订阅。同一 Apple ID 可在 iPhone 与 Mac 点恢复购买。

买了但还是锁着

到设置里点恢复购买，并确认用的是付款时的 Apple ID。沙盒账号和正式账号的购买不能混用。

测试服务商失败

核对 Key 是否完整、该服务商是否仍提供这个模型，以及网络能否访问其接口。局域网或本机模型请确认地址指向你自己的服务。
