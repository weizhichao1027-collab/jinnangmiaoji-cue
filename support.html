请不要发送 API Key、私人录音或未脱敏的转录，除非你明确决定分享。

不填 Key 也能开始

从 App Store 安装，允许麦克风和语音识别，然后点开始。本机听写一直免费，也不计试用次数。若要云端转录或 AI 接话，再在设置里粘贴你自己的 Key，保存并测试。

本机听写没有出字

先允许麦克风。本机听写还需要语音识别权限。到系统设置打开这两项后，回到应用再点开始。部分语言若没有离线模型，会走 Apple 的语音识别，此时需要网络。

怎么接自己的 API

打开设置，选一家 AI 或转录服务商，粘贴 Key，点保存并测试。常见服务商不用改地址和模型。也可以手填兼容的对话补全地址。本机听写可以先用，不必填转录 Key。

试用和买断怎么算

本机听写不计数。每一次成功的云端听写、每一次 AI 生成、以及场上的实时翻译，各算 1 次，一共 20 次。之后是 App Store 非消耗型一次性买断，不是自动续期订阅。价格约 US$9.99，当地价格由 Apple 显示。

买了但还是锁着

到设置里点恢复购买，并确认用的是付款时的 Apple ID。沙盒账号和正式账号的购买不能混用。家庭共享打开后，同一家庭的成员也可以使用这次买断。

测试服务商失败

核对 Key 是否完整、该服务商是否仍提供这个模型，以及网络能否访问其接口。局域网或本机模型请确认地址指向你自己的服务。不要把完整 Key 发到邮箱。

当场翻译算不算试用

算。场上的实时翻译和云端听写、AI 接话共用这 20 次。翻译走你配置的服务商，不是我们托管的额度。

切到后台就停了

这是预期行为。听写只在前台进行。回到主屏幕或锁屏后，麦克风会停。历史回放仍可在打开应用时听。

iPhone 买了，Mac 怎么开

在 Mac 上用同一个 Apple ID 打开应用，到设置里点恢复购买。这是非消耗型买断，不是按设备另收一次。
